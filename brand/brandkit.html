09 System

Use it like this

  • Ember marks the one thing that matters on a screen: the main button, a highlight, the live dot.
  • Graphite text and hard shadows on Chalk. Dark Graphite chapters for the hero and footer.
  • Mono only for real data: timings, costs, model names, code.

Avoid

  • White text on Ember. It fails contrast; use Graphite.
  • Purple-blue gradients, glows, robot imagery, sparkles.
  • Ember as body text on Chalk (2.8:1). Punctuation and shapes only.
